Une source est une **intégration** : l'API la lit, garde ses données le temps de son intervalle de rafraîchissement, et remplit les panneaux « source » qui l'utilisent. Chaque type de source annonce ses **vues** (capacités). Les administrateurs gèrent les sources ; tout le monde peut les utiliser dans une playlist.

| Source | Vues | Réglages |
|---|---|---|
| **Rocket PMS** | Message d'accueil (au prénom du voyageur), voyageur présent, prochaine arrivée, Wi-Fi, départ, règlement, bonnes adresses, contacts | Adresse de l'API, jeton du lien « écran TV » du livret d'accueil, langue |
| **Rocket Place** | Valeurs (liste) | Adresse de l'API, identifiant du lieu, jeton d'application `rpl_…`, utilisateur au nom duquel agir, valeurs à garder |
| **Web JSON** | Valeurs (liste), texte | Adresse (GET), titre, valeurs `Libellé \| chemin \| unité`, chemin d'un texte, en-tête `Authorization` |

**Lire maintenant** interroge la source et montre ce qu'elle renvoie ; l'œil montre les dernières données gardées.

## Pannes

Si une source ne répond plus, les écrans gardent ses **dernières données** ; l'erreur s'affiche dans **Sources** et sur le tableau de bord (« Sources des écrans », vérifiées toutes les 5 minutes par le worker). Un nouvel essai a lieu au plus tôt une minute plus tard. Une source peut aussi demander à être relue à une heure précise (`reloadAt`) : Rocket PMS le fait 30 minutes avant chaque arrivée, pour accueillir le nouveau voyageur par son prénom.

## Identifiants

Les jetons, clés et en-têtes des sources ne sont **pas** dans `.env` : ils sont saisis dans l'administration et **chiffrés en base** (libsodium secretbox) avec la clé maîtresse `ROCKET_SECRETS_KEY` (64 caractères hexadécimaux, `openssl rand -hex 32`). L'API ne les renvoie jamais : elle indique seulement lesquels sont enregistrés. Laisser un champ vide garde la valeur enregistrée.

::warning
Changer `ROCKET_SECRETS_KEY` rend les identifiants enregistrés illisibles : ils doivent être saisis à nouveau. Sans `ROCKET_SECRETS_KEY`, la clé est dérivée de `APP_SECRET` (développement uniquement).
::

Le chiffrement passe par l'interface `App\Secret\SecretStoreInterface`, pour pouvoir le confier plus tard au coffre de rocket-core.

## Ajouter un type de source

Implémentez `App\Source\SourceTypeInterface` (identifiant, nom, icône, vues, champs du formulaire, validation des réglages, lecture) : la classe est enregistrée automatiquement et apparaît dans **Sources**. `fetch()` renvoie des données normalisées (`welcomeText`, `guest`, `nextArrival`, `wifi`, `checkoutInfo`, `items`, `text`, `title`, `reloadAt`…, voir `App\Source\SourceViews`).
