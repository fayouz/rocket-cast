La démo lance Rocket Cast avec des données prêtes à l'emploi :

- des comptes locaux et LDAP (annuaire OpenLDAP) ;
- trois sources servies par l'API elle-même (fausses réponses de **Rocket PMS**, **Rocket Place** et d'une API **JSON**), sans réseau externe ;
- la playlist **Accueil voyageurs (démo)**, qui utilise tous les types de panneaux ;
- l'écran **TV du salon (démo)**, au lien connu, et une tablette à appairer ;
- une application externe, avec un jeton connu.

::tabs
  :::tabs-item{label="En local" icon="i-lucide-laptop"}
  ```bash [Terminal]
  docker compose -f compose.yaml -f compose.demo.yaml up -d --build
  ```

  Puis ouvrez http://localhost:3600 (Rocket Cast) et http://localhost:3601 (cette documentation et le changelog).
  :::

  :::tabs-item{label="GitHub Codespaces" icon="i-simple-icons-github"}
  1. Sur GitHub : **Code → Codespaces → Create codespace**.
  2. Attendez la fin de la commande de démarrage (quelques minutes la première fois).
  3. Ouvrez le port 3600 (Rocket Cast) depuis l'onglet **Ports**.
  :::
::

## Scénarios

1. **L'écran.** Ouvrez http://localhost:3600/s/demo-screen-rocket-cast-0000000000000000000 : message d'accueil au prénom de Camille, horloge, météo de Marseille, Wi-Fi avec QR code, prochaine arrivée, départ, valeurs des capteurs, infos du bureau, texte, QR code, image.
2. **Hors ligne.** Arrêtez l'API (`docker compose -f compose.yaml -f compose.demo.yaml stop api`) : l'écran continue avec le dernier contenu et affiche « Hors ligne ». Redémarrez-la : il reprend seul.
3. **L'éditeur.** Connecté, ouvrez **Playlists → Accueil voyageurs (démo)** : sélectionnez un panneau pour le voir dans l'aperçu, changez un texte, la couleur, une programmation ; enregistrez : l'écran se met à jour dans la minute.
4. **Appairage.** Dans un autre onglet, ouvrez http://localhost:3600/pair?new : un code s'affiche. Dans **Écrans → Appairer un écran**, saisissez-le : l'onglet ouvre tout seul son lien d'écran.
5. **Sources.** Avec `admin@example.org`, **Sources** : **Lire maintenant**, les dernières données, les champs de chaque intégration (les jetons ne sont jamais réaffichés).
