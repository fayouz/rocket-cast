## Aujourd'hui : le lien « écran TV » du livret d'accueil

La source **Rocket PMS** lit la route publique existante de Rocket PMS :

```http
GET {baseUrl}/api/public/tv/{tvToken}?lang=fr
```

`tvToken` (43 caractères) est le jeton du lien « écran TV » du livret d'accueil d'un logement ; il est chiffré dans Rocket Cast. Champs utilisés :

| Champ Rocket PMS | Donnée Rocket Cast | Vue |
|---|---|---|
| `property` | `title` | toutes |
| `content.welcomeText` | `welcomeText` | Message d'accueil |
| `guest.firstName`, `guest.departure`, `guest.checkOut` | `guest` | Message d'accueil, Voyageur présent, Départ |
| `nextArrival`, `nextArrivalAt` | `nextArrival {date, at}` | Prochaine arrivée |
| `content.wifiSsid`, `content.wifiPassword` | `wifi {ssid, password}` | Wi-Fi |
| `content.checkoutInfo` | `checkoutInfo` | Départ |
| `content.houseRules`, `content.localTips`, `content.contacts` | `houseRules`, `localTips`, `contacts` | Règlement, Bonnes adresses, Contacts |
| `reloadAt` | `reloadAt` | relecture 30 minutes avant l'arrivée |
| `latitude`, `longitude`, `style.accent` | gardés pour plus tard | — |

`{{guest}}` est déjà remplacé par le prénom côté Rocket PMS. Rocket Cast ne lit pas la couverture (`/cover`).

## Plus tard : une route dédiée

Changements prévus côté Rocket PMS (non faits) :

1. `GET /api/cast/properties/{id}` authentifiée par **jeton d'application** Rocket PMS (`rpm_…`, avec un droit de lecture seule), pour ne plus dépendre du jeton public du lien TV et choisir le logement par identifiant ;
2. même contenu que `/api/public/tv/{token}` plus `arrivals` (les 3 prochaines, prénom et date) et `checkouts` du jour, pour des panneaux « arrivées du jour » dans un hall ;
3. un webhook (ou un champ `version`) pour que Rocket Cast relise la source dès qu'un livret change, au lieu d'attendre l'intervalle de rafraîchissement.

La source Rocket PMS acceptera alors les deux modes (lien TV ou jeton d'application).
