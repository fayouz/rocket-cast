Toutes les routes répondent en JSON. Les routes d'administration demandent un compte (JWT ou jeton d'application `rct_…`, voir [Authentification](/api/authentication)) ; la gestion des sources demande le rôle administrateur.

## Administration

| Méthode | Route | Rôle |
|---|---|---|
| `GET` `POST` | `/api/screens` | Écrans ; `?place=<uuid>` ne garde que les écrans de ce lieu Rocket Place ; la création renvoie une fois `token`, `kioskPath`, `kioskUrl` |
| `GET` `PATCH` `DELETE` | `/api/screens/{id}` | `name`, `location`, `placeId` (UUID d'un lieu Rocket Place ou `null`), `placeName` (nom affiché, gardé en cache), `playlistId`, `orientation` (`landscape`, `portrait`), `timezone`, `locale`, `enabled` |
| `POST` `DELETE` | `/api/screens/{id}/token` | Nouveau lien (renvoyé une fois) ou révocation |
| `POST` | `/api/screens/pair` | `{code, screenId?}` ou `{code, name, playlistId…}` : appairage d'un écran qui affiche `/pair` |
| `GET` `POST` | `/api/playlists` | Playlists |
| `GET` `PATCH` `DELETE` | `/api/playlists/{id}` | `name`, `description`, `accent` (`#RRGGBB`), `theme` (`dark`, `light`), `panels` |
| `POST` | `/api/playlists/{id}/duplicate` | Copie |
| `POST` | `/api/playlists/preview` | `{panels, timezone}` : ce qu'un écran afficherait, chaque panneau marqué `activeNow` |
| `GET` | `/api/source-types` | Types de sources : vues et champs du formulaire |
| `GET` | `/api/sources`, `/api/sources/{id}` | Sources (réglages et identifiants enregistrés : administrateurs seulement) |
| `POST` `PATCH` `DELETE` | `/api/sources`, `/api/sources/{id}` | Administrateurs ; `secrets` : absent ou `null` garde, `""` supprime |
| `POST` | `/api/sources/{id}/test` | Lit la source maintenant |
| `GET` | `/api/sources/{id}/payload` | Dernières données gardées |

Un panneau : `{id, type, duration, enabled, schedule: {days: [1…7], from: "HH:MM", until: "HH:MM"} | null, settings}`. Les réglages inconnus sont ignorés ; une erreur renvoie `422` avec le numéro du panneau.

## API publique des écrans

Sans compte, limitée par adresse IP, `Cache-Control: no-store`, `X-Robots-Tag: noindex`.

```http
GET /api/public/screens/{jeton}
```

```json
{
  "screen": { "name": "TV du salon", "orientation": "landscape", "timezone": "Europe/Paris", "locale": "fr-FR", "enabled": true },
  "playlist": { "name": "Accueil", "accent": "#0ea5e9", "theme": "dark" },
  "panels": [
    { "id": "a1", "type": "clock", "duration": 10, "settings": { "label": "", "showDate": true, "showSeconds": false } },
    { "id": "b2", "type": "source", "duration": 12, "settings": { "view": "welcome", "title": "" },
      "data": { "title": "Loft du Vieux-Port", "text": "Bienvenue !", "firstName": "Camille" } }
  ],
  "generatedAt": "2026-09-28T08:00:00+00:00",
  "reloadAt": "2026-09-28T10:15:00+02:00",
  "pollSeconds": 60,
  "version": "3f2a…"
}
```

`404` : lien invalide ou révoqué. `429` : trop de requêtes.

Appairage :

```http
POST /api/public/pairings                 → 201 {code: "K7F-3QX", secret, expiresAt, pollSeconds}
POST /api/public/pairings/poll {secret}   → {status: "pending"} | {status: "paired", token, path} (une seule fois)
```

## Lieu d'un écran

Un écran peut être rattaché à un lieu Rocket Place (`placeId`, facultatif) : Rocket Cast ne l'appelle pas, il garde seulement l'identifiant et le nom donné (`placeName`) pour l'affichage. Les autres applications (Rocket Host…) retrouvent ainsi les écrans d'un logement avec `GET /api/screens?place=<uuid>`. Sans `placeId`, le nom du lieu est effacé.
